# Rising feedback

Public corrections and feedback for [rising.dev](https://rising.dev).

[Report a correction](https://github.com/momchilon/rising-feedback/issues/new?template=correction.yml) when a project description, number, category or announcement needs a change. Include the Rising page and a public source supporting the correction. Reports are public: do not include credentials or private information.

Rising explains GitHub projects in English and follows selected AI model and product announcements. [Read the methodology](https://rising.dev/methodology/).
